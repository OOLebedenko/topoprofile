# TopoProfile

TopoProfile is an experimental project for working with digital elevation models (DEM) and interactive terrain
visualization.

## Current focus

The current goal is to build an interactive 3D terrain map using tiled DEM data.

This stage focuses on:

* preparing and tiling DEM data;
* loading terrain tiles dynamically;
* rendering terrain in an interactive 3D map;
* combining 3D terrain with a 2D basemap.

## Long-term idea

The project started from a broader idea: using terrain profiles to estimate where a mountain photograph was taken.

The 3D terrain map is the first step in exploring this idea.
In the future, it could be used to visualize and test candidate locations found by comparing photograph skylines with
synthetic terrain profiles generated from DEM data.
